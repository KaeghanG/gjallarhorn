# Controls

Gjallarhorn works with **Xbox** (XInput, including the Guide button) and **PlayStation** (DualSense / DualShock) controllers, and with a keyboard. PlayStation buttons map to the Xbox layout: Cross = A, Circle = B, Square = X, Triangle = Y, Share/Create = Back/View, Options = Start/Menu.

## Couch mode: main screens

| Button | Action |
|---|---|
| **Stick / D-pad** | Move between tiles and rows |
| **A** | Select / play / install |
| **B** | Back, or leave couch mode from the top level |
| **X** | Favourite a game |
| **Y** | Options menu for the highlighted game |
| **LB / RB** | Previous / next tab |
| **L2 / R2** | Jump to the previous / next letter (A to Z) |
| **View (Back)** | Search |
| **Menu (Start)** | Game details page |
| **Left** on the first tile | Open the sidebar |
| **Up** from the first row | Move focus to the tab bar |

Buttons **Back** and **Start** act when you *release* them, so holding both for the in-game menu never triggers a Search or Details by accident.

## Sidebar

| Button | Action |
|---|---|
| **Up / Down** | Choose an entry |
| **A** | Open it |
| **B / Right / Y** | Close the sidebar |

## In-game menu (hold Back + Start)

Hold **Back + Start** (about one second). Works in a game, on the desktop, or over an emulator.

| Button | Action |
|---|---|
| **Up / Down** | Choose an item |
| **Left / Right** | Adjust volume or brightness |
| **A** | Run the item (A on Volume toggles mute) |
| **B** or **Start** | Resume / close the menu |
| **X** | Dismiss a game invite |

## Page-specific controls

| Page | Controls |
|---|---|
| **Friends** | Up/Down friend · **A** chat · **Y** join their game · **X** open Steam chat · **Start** twice signs out |
| **Chat keyboard** | D-pad moves · **A** types · **X** delete · **Y** space · **Start** send · **B** back |
| **Workshop** | **LB/RB** sort · **A** subscribe/unsubscribe · **X** view in Steam · **Y** Workshop home · **B** back |
| **Downloads** | Up/Down · **A** open in Steam · **X** pause/resume (opens Steam's download manager) · **B** back |
| **Controllers** | **X** button test · **B** back |
| **Achievements** | Up/Down scroll · **LB/RB** jump 10 · **B** back |
| **Power menu** | Up/Down · **A** choose · confirm with Left/Right then **A** · **B** cancel |
| **Play reports** | Up/Down sessions · **B** back |

## Keyboard (couch mode)

| Key | Action |
|---|---|
| Arrow keys | Move |
| **Enter** | Select |
| **Esc** | Back |
| **Q / E** | Previous / next tab (in Search, letters type instead) |
| **F** | Favourite |
| **O** | Options |
| **Tab** | Details |
| **/** | Search |

## Desktop app

| Shortcut | Action |
|---|---|
| **Ctrl + Shift + Space** | Quick launcher (global, even when minimised) |
| **Hold Back + Start** (controller) | Open couch mode or the menu from anywhere |
