Under the hood

How it works

🔎

1. It reads, it doesn't log in

Gjallarhorn reads what Steam, Epic, GOG, Ubisoft, EA, Battle.net and Riot already installed. No store passwords, no accounts.

🚀

2. Games start the normal way

Play launches the game through its own store, so DRM, anti-cheat and cloud saves work exactly as before.

🎛️

3. A background controller layer

A tiny helper reads Xbox and PlayStation pads even when another window has focus. That is how Back + Start works over a running game.

🔒

4. Everything stays local

Settings, chat history, play reports and cached art live on your PC. No telemetry, ever.

Questions

FAQ

Does it replace Steam?

It replaces Steam's front end (Big Picture), not Steam itself. Steam games still run through Steam, so Steam must be running.

Is it safe?

It is free, open source and has no account, ads or telemetry. The installer is not code-signed yet, so Windows SmartScreen warns the first time: choose More info, then Run anyway.

Do I have to log in to Epic, GOG or Ubisoft in the app?

No. It reads what those launchers installed and starts games through them.

Why not the Home button for the menu?

Steam grabs the Guide button for its own overlay. Back + Start is something Steam does not intercept, so it always works. Gjallarhorn also closes Steam's Big Picture window if the Guide button opens it.

Which controllers work?

Xbox (XInput) and PlayStation DualSense / DualShock, plus most pads Windows exposes. A keyboard works too.

Does it include ROMs or BIOS?

Never. It does not download, host or help find ROMs, BIOS files, firmware or keys. Cover art comes from the libretro-thumbnails project and a public Switch title list.

Does it work on Linux or Steam Deck?

No. It uses Windows features (PowerShell, XInput, Win32).

The name

Why "Gjallarhorn"?

In Norse myth the Gjallarhorn is Heimdall's horn, the call that rings across all nine realms at Ragnarök. In Destiny it became the legendary rocket launcher everyone remembers. The author loved the best launcher named Gjallarhorn so much that they set out to build a fire launcher with the same name, one that calls every game you own with a single blast.

An independent fan project. No Bungie assets are used; the war-horn logo is an original drawing.

Get started

Install in a minute

  1. Download the installer from the latest release and run it. Windows may show a SmartScreen warning because the installer is not code-signed yet: choose More info, then Run anyway.
  2. Open Gjallarhorn. It finds your installed games automatically. Plug in a controller and choose Couch mode in the sidebar.
  3. Optional: paste a free Steam Web API key in Settings, Store accounts to unlock owned-games and the Workshop browser.

Build from source: npm install then npm run dev. Everything stays on your PC: no account, no telemetry. Gjallarhorn never downloads ROMs, BIOS files, firmware or keys.
