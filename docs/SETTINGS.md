# Gjallarhorn Settings Reference

A reference of every user-facing setting, grouped by the sections on the Settings page. For each setting: its name in the UI, what it does, its default value, and the key stored in `settings.json`.

## Where settings live

All settings are stored as a single JSON file at **`%APPDATA%\Gjallarhorn\settings.json`** (on Windows this is typically `C:\Users\<User>\AppData\Roaming\Gjallarhorn\settings.json`).

Other files in the same Electron userData folder (`%APPDATA%\Gjallarhorn\`):

| File / Folder | Purpose | Generated by |
|---|---|---|
| `settings.json` | All user settings | Gjallarhorn itself (written on every change) |
| `session-reports.json` | GPU session reports (temp, util, power, VRAM sampled via nvidia-smi) | `electron/lib/session.cjs` |
| `chat-history.json` | Steam chat message history | `electron/lib/steamchat.cjs` |
| `steam-chat-token.bin` | Encrypted Steam Web API refresh token for chat login | `electron/lib/steamchat.cjs` (via Electron safeStorage) |
| `price-history.json` | Local price history log from IsThereAnyDeal | `electron/lib/prices.cjs` |
| `playtime.json` | Per-game playtime totals and session counts | `electron/lib/session.cjs` |
| `thumbs/` | ROM cover art downloaded from libretro-thumbnails GitHub | `electron/lib/roms.cjs` |
| `launch-debug.log` | Launch, process detection and window placement debug log | `electron/lib/session.cjs`, `electron/lib/workshop.cjs`, `electron/main.cjs` |
| `backups/<gameKey>/` | Per-game tweak and save backups (see each game's subfolder) | `electron/lib/tweaks.cjs` |
| `emulators/` | Emulator installs managed by Gjallarhorn | `electron/lib/emulators.cjs` (in dev mode stored under the repo root; in packaged builds under userData) |

> **Tip:** Edit `settings.json` directly to reset a setting. After saving, restart Gjallarhorn — there is no "reload settings" command.

## Region

| UI name | What it does | Default | Key |
|---|---|---|---|
| Store region | Controls which country Steam and Epic use for prices and free-game listings. CheapShark cross-store comparison is always in USD regardless of this setting. | Auto-detect (reads Windows locale) | `region` |

The select dropdown offers preset country codes; selecting "Auto" leaves the value empty so Gjallarhorn auto-detects from Windows. The detected region appears as `(detected: <CC>)` alongside the "Auto" option but is **not** stored in settings — it is computed at runtime.

## Game Boost

Applied while a game launched from Gjallarhorn is running; undone automatically when the game quits.

| UI name | What it does | Default | Key |
|---|---|---|---|
| Open games on the screen I launched from | If a game opens on a different monitor, Gjallarhorn moves it to the monitor where you clicked Launch (or where the quick launcher window was). | On (`true`) | `launchOnSameScreen` |
| High CPU priority | Gives the game process "High" process-priority class so background apps yield. | On (`true`) | `boost.priority` |
| Pause Wallpaper Engine | Stops Wallpaper Engine's GPU usage while you play, then resumes it on quit. | On (`true`) | `boost.wallpaper` |

## Key shops (G2A, Loaded / CDKeys)

Grey-market key shops show prices from third-party sellers. Keys can be region-locked or revoked; always labelled "Key shop" in the UI.

| UI name | What it does | Default | Key |
|---|---|---|---|
| Show key-shop prices | Toggle whether grey-market shop prices appear on game pages. | On (`true`) | `showKeyshops` |
| GG.deals API key | Free API key from gg.deals → Settings → API. Required because G2A and Loaded block app-based scraping; GG.deals tracks price data for them. Log in at gg.deals to obtain one. | Empty | `ggKey` |
